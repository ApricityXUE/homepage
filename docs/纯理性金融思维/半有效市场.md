# 有效市场理论

总有人说“市场总是对的”，真的如此么？


金融市场的作用和有效市场的条件：
- 充足的流动性
- 对信息的充分且正确的反应

## 半有效市场


如果市场是绝对有效的，那投资大盘指数就是最优解，因为个人完全无法获取超额收益

这种认识当然是有用的，因为90%的基金经理收益率长期来看跑不过S&P500

不过那10%的现实告诉我们，战胜市场是有希望的

现实是，短期来看市场犯错太正常了，因为市场不过是一群参与者，一群人构成的，不论是机构、游资、散户都看不到所有的信息，没有人有知晓过去与未来的上帝视角，于是在事件冲击下不同人会有不同的理解，人们开始用钱投票，于是，正如二战前德国人民选出了希特勒一样，一群人的错误未来也会有一群人去纠正。

这种事情太多了，近的有DeepSeek横空出世之后NVDA的股价暴跌（能高效训练又不是不要“铲子”了，怎么会跌呢？），远的有2000年.com泡沫（这么多圈钱公司为什么市场就傻乎乎地认了呢？）

所有的信息全部立刻体现在了股价之中，也是不现实的。

也因此总有人能够长期战胜市场，也让傻子们愿意去做各种奇形怪状的博弈。
