# 大类资产配置

在前言中，我们提到“存银行是投资，买股票是投资，买房是投资，学习与自我提升同样是投资”，事实上这是把人生“资本化”，有人不喜欢这样，但理性来看是挺有用的一件事情。

比如说，在当前的市场环境下，买房子和买车是一件很亏的事情。大部分一线城市的房子租售比很低，导致买房子的一次性投入可能这辈子很难通过收租回本，而贷款买房，则很可能租金不能覆盖月供，因此非刚需情况下，在当前的房价下行周期，买房对理性人来说是没什么吸引力的事情。买车也是一样，尤其是豪车，如果不是因为身处的圈子带来的虚荣心，买车的一次性支出很容易大于一辈子打车付出的折现现金流，同样划不来。

$$NPV = \sum_{t=1}^{T} \frac{CF_t}{(1+r)^t} - P_0$$

站在这个视角看，我们人生的很多决策都可以金融化，这会消除很多当下的情绪冲击，也逼着我们拉长眼光看待事物。更抽象的例子就是读书，小时候读书是一个持续多年的投入，而工作之后则迎来漫长的回报周期。当然，孩子是不理性的，也往往是短视的，于是眼下的精力被胡乱投资在了未来回过头看留不下东西的消耗上。资本市场中的大部分投资又何尝不是如此呢？

所以，我们的人生其实本身就是一场广义的”大类资产配置“。
