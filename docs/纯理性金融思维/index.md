# 前言

本站内容中的“我”，是一个被抽象化之后的理性经济人，只不过注入了我本人的风险偏好。

所以“我”，

不追逐热点，
不沉迷预测，
不幻想未来终局。

现实世界中的我当然远不能绝对理性，因此本文所有内容仅用于知识讨论与框架构建。
真正的投资决策，应由读者根据自身的风险承受能力、现金流结构与价值观独立作出。

# 投资的本质

投资是一种“低买高卖”的艺术，
更是跨越时间配置资源。

是把今天的确定性，
交给未来的不确定性。

是相信未来的生产力，
会回馈现在的耐心。

在金融语言中，这是一个净现值问题：

$NPV = \sum_{t=1}^{T} \frac{CF_t}{(1+r)^t} - P_0$

在更广义的层面，它是一种文明行为。

一个社会愿意投资，
意味着它愿意延迟消费，
愿意为未来承担风险，
愿意相信长期秩序不会崩塌。

存银行是投资，
买股票是投资，
买房是投资，
学习与自我提升同样是投资。

投资的真正差别，
不在于形式，
而在于承担了怎样的不确定性。
